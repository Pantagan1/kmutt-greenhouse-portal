01. บทนำและแผนที่การพัฒนาแบบจำลอง (Project Overview & Roadmap)

แบบจำลองดิจิทัลทวินโรงเรือนสุพรรณบุรี (Greenhouse_DigitalTwin_KMUTT.Examples.Suphanburi_Greenhouse) เป็นแบบจำลองฟิสิกส์ชั้นสูงที่จำลองพลศาสตร์จุลภูมิอากาศ (Microclimate Dynamics) ของโรงเรือนหลังคาโค้งครึ่งวงกลม ($R = 3\text{ m}$) ขนาดกว้าง $6\text{ m} \times 12\text{ m}$ (ยาว) $\times 5.5\text{ m}$ (สูงรวม) มีปริมาตรอากาศ $349.65\text{ m}^3$ ปลูกมะเขือเทศเชอร์รี่ พร้อมติดตั้งมุ้งกันแมลง 16 เมชรอบด้านข้าง และใช้ข้อมูลตรวจวัดสภาพอากาศจริง ERA5 รายชั่วโมงตลอด 365 วัน

💡 รูปแบบการเรียนรู้สองทางขนานกัน (Dual-Track Learning Approach)

ในแต่ละขั้นตอนของคู่มือฉบับนี้ จะแบ่งการอธิบายออกเป็น 2 มุมมองควบคู่กัน:
• 🎨 OMEdit GUI Track: วิธีการคลิกเมาส์, การสร้างคลาส, การวาดบล็อกไอคอน (Icon View), การจัดวาง และการลากสายเชื่อมต่อ (Diagram View)
• 💻 Modelica Code Track: ไวยากรณ์ตัวหนังสือที่เกิดขึ้นจริงในเบื้องหลัง (Text View), คำสั่ง Annotation, และสมการคณิตศาสตร์

📦 1. โครงสร้างแพ็กเกจ
จัดระเบียบไฟล์ตามมาตรฐาน Modelica แยกโฟลเดอร์ Components, Examples และ Resources/Data
🛡️ 2. Custom Block 16-Mesh
สร้างคอมโพเนนต์มุ้งกันแมลงคำนวณ Darcy-Forchheimer drag, stack effect และการถ่ายเทความร้อน-ความชื้น
🌤️ 3. แหล่งข้อมูลอากาศ ERA5
ผูกตารางสภาพอากาศจริง 8,760 แถวด้วย CombiTimeTable พร้อมระบบ Fallback เป็นคลื่น Sine Wave
🧩 4. การประกอบโมเดลหลัก
เชื่อมต่อ Cover, Air, Canopy, Floor เข้ากับมุ้ง 16-Mesh ผ่านพอร์ตฟิสิกส์ HeatPort และ WaterMassPort
📡 5. เซนเซอร์ 15 จุด 3 มิติ
คำนวณการกระจายตัวอุณหภูมิและความชื้นแนวยาว (ต้นลม WSW ไปท้ายลม) และแนวดิ่ง 3 ระดับความสูง
📊 6. จำลองผลและ Export CSV
รันการจำลอง 1 ปีเต็ม ตรวจสอบความถูกต้อง และ Export ตารางข้อมูลไปวิเคราะห์ต่อใน Excel/Python

04. ขั้นตอนที่ 3: การสร้างบล็อกมุ้งกันแมลง 16-Mesh (InsectScreen_16Mesh Component)

ขั้นตอนที่ 3.1

ทฤษฎีและสมการของบล็อก InsectScreen_16Mesh

มุ้งกันแมลงขนาด 16 เมช (รูตะแกรงกว้างประมาณ $1.25\text{ mm}$, เส้นด้าย $0.3\text{ mm}$) มีความพรุน $\varepsilon = 0.60$ ทำให้เกิดแรงต้านทานการไหลของอากาศตามสมการ Darcy-Forchheimer ทีมวิจัยจึงได้พัฒนาบล็อกคำนวณการระบายอากาศและสมดุลความร้อน-ความชื้นขึ้นมาโดยเฉพาะ:

$$Q_{\text{wind}} = C_d A_{\text{vent,side}} \max(0.1, u_{\text{wind}}) \sqrt{\Delta C_p}$$ $$Q_{\text{stack}} = C_d A_{\text{vent,roof}} \sqrt{\frac{2 g \Delta h \max(0.0, T_{\text{air,in}} - T_{\text{amb,out}})}{\max(273.15, T_{\text{amb,out}})}}$$ $$Q_{\text{vent,total}} = \sqrt{Q_{\text{wind}}^2 + Q_{\text{stack}}^2}$$ $$Q_{\text{vent,heat}} = \rho_{\text{air}} Q_{\text{vent,total}} c_{p,\text{air}} (T_{\text{air,in}} - T_{\text{amb,out}})$$
🎨 แถบเครื่องมือ Icon View ใน OMEdit
ขั้นตอนการสร้างและวาดรูปบล็อกมุ้ง 16 เมช:
1. คลิกขวาที่ Components → เลือก New Modelica Class → Name: InsectScreen_16Mesh (Specialization: Model)
2. ดับเบิ้ลคลิกเปิดโมเดล แล้วคลิกแท็บ Icon View (ไอคอนรูปพู่กัน/สี่เหลี่ยมด้านบน)
3. วาดกรอบสี่เหลี่ยม: เลือกเครื่องมือ Rectangle ลากพิกัดจากมุมซ้ายบน (-90, 90) ถึงขวาล่าง (90, -90)
- ดับเบิ้ลคลิกตั้งสีเส้นขอบ: #008080 (Teal), ความหนา 1.5
- สีพื้นหลัง: #E6F8F8 (Cyan จาง), Fill Pattern: Solid
4. วาดลายเส้นตะแกรงมุ้งลวด: ใช้เครื่องมือ Line ลากเส้นประแนวตั้ง 5 เส้น และแนวนอน 5 เส้น (Line Pattern: Dot)
5. วางตัวหนังสือ: ใช้เครื่องมือ Text ใส่ข้อความ 16-MESH INSECT SCREEN และ Porosity: %mesh_porosity
6. การใส่พอร์ตเชื่อมต่อ (Connectors):
- ฝั่งซ้าย: ลาก Modelica.Blocks.Interfaces.RealInput มาวาง 4 ตัว (T_air_in, T_amb_out, wind_speed, RH_amb_out)
- ฝั่งขวา: ลาก Modelica.Thermal.HeatTransfer.Interfaces.HeatPort_a (ชื่อ heatPort)
- ฝั่งขวา: ลาก Greenhouses.Interfaces.Vapour.WaterMassPort_a (ชื่อ massPort)
- ฝั่งขวา: ลาก Modelica.Blocks.Interfaces.RealOutput 3 ตัว (ACH, Q_vent, MV_vent)

โค้ดต้นฉบับ Modelica ฉบับสมบูรณ์ของคอมโพเนนต์ InsectScreen_16Mesh.mo:

Greenhouse_DigitalTwin_KMUTT/Components/InsectScreen_16Mesh.mo 
within Greenhouse_DigitalTwin_KMUTT.Components;
model InsectScreen_16Mesh
  "16-Mesh Insect Screen Natural Ventilation Model (Darcy-Forchheimer Drag, Wind-Driven + Thermal Buoyancy Stack Effect)"

  /****************************************************************************
   * PARAMETERS: 16-Mesh Porous Screen & Discharge Coefficient
   ****************************************************************************/
  parameter Real mesh_porosity = 0.60
    "16-Mesh screen porosity (epsilon = 0.55 - 0.65)"
    annotation (Dialog(group="16-Mesh Insect Screen Specification"));

  parameter Modelica.Units.SI.Length thread_diameter = 0.30e-3
    "Thread / wire diameter (m)"
    annotation (Dialog(group="16-Mesh Insect Screen Specification"));

  parameter Real Cd_mesh = 0.42
    "Discharge coefficient taking into account 16-mesh porous drag (Valera 2006 & Miguel 1998)"
    annotation (Dialog(group="16-Mesh Insect Screen Specification"));

  /****************************************************************************
   * PARAMETERS: Ventilation Openings & Geometry (Suphan Buri Greenhouse)
   ****************************************************************************/
  parameter Modelica.Units.SI.Area A_vent_side = 90.0
    "Total side wall insect screen area: 2*(12*2.5) + 2*(6*2.5) = 90 m2"
    annotation (Dialog(group="Ventilation Openings & Geometry"));

  parameter Modelica.Units.SI.Area A_vent_roof = 12.0
    "Effective roof ridge ventilation opening area (m2)"
    annotation (Dialog(group="Ventilation Openings & Geometry"));

  parameter Modelica.Units.SI.Length dh_stack = 2.75
    "Vertical stack height between side openings and roof ridge (m)"
    annotation (Dialog(group="Ventilation Openings & Geometry"));

  parameter Real delta_Cp = 0.35
    "Wind pressure coefficient differential (Cp_windward - Cp_leeward)"
    annotation (Dialog(group="Ventilation Openings & Geometry"));

  parameter Modelica.Units.SI.Volume V_gh = 349.65
    "Greenhouse interior air volume (m3)"
    annotation (Dialog(group="Ventilation Openings & Geometry"));

  /****************************************************************************
   * INPUT CONNECTORS
   ****************************************************************************/
  Modelica.Blocks.Interfaces.RealInput T_air_in(unit="K")
    "Interior air temperature (K)"
    annotation (Placement(transformation(extent={{-140,40},{-100,80}})));

  Modelica.Blocks.Interfaces.RealInput T_amb_out(unit="K")
    "Outdoor ambient temperature (K)"
    annotation (Placement(transformation(extent={{-140,-20},{-100,20}})));

  Modelica.Blocks.Interfaces.RealInput wind_speed(unit="m/s")
    "Outdoor wind speed at reference height (m/s)"
    annotation (Placement(transformation(extent={{-140,-80},{-100,-40}})));

  Modelica.Blocks.Interfaces.RealInput RH_amb_out(min=0, max=1)
    "Outdoor ambient relative humidity (0 to 1)"
    annotation (Placement(transformation(extent={{-140,-140},{-100,-100}})));

  /****************************************************************************
   * THERMAL & TELEMETRY OUTPUT CONNECTORS
   ****************************************************************************/
  Modelica.Thermal.HeatTransfer.Interfaces.HeatPort_a heatPort
    "Thermal heat port connected to indoor air"
    annotation (Placement(transformation(extent={{100,40},{140,80}}),
                           iconTransformation(extent={{100,40},{140,80}})));

  Greenhouses.Interfaces.Vapour.WaterMassPort_a massPort
    "Water mass port for moisture ventilation exchange"
    annotation (Placement(transformation(extent={{100,100},{140,140}}),
                           iconTransformation(extent={{100,100},{140,140}})));

  Modelica.Blocks.Interfaces.RealOutput ACH(unit="1/h")
    "Natural ventilation rate in Air Changes per Hour (ACH)"
    annotation (Placement(transformation(extent={{100,-20},{140,20}}),
                           iconTransformation(extent={{100,-20},{140,20}})));

  Modelica.Blocks.Interfaces.RealOutput Q_vent(unit="W")
    "Heat removal rate by natural ventilation through insect screen (W)"
    annotation (Placement(transformation(extent={{100,-80},{140,-40}}),
                           iconTransformation(extent={{100,-80},{140,-40}})));

  Modelica.Blocks.Interfaces.RealOutput MV_vent(unit="kg/s")
    "Moisture removal rate by natural ventilation through insect screen (kg/s)"
    annotation (Placement(transformation(extent={{100,-140},{140,-100}}),
                           iconTransformation(extent={{100,-140},{140,-100}})));

  /****************************************************************************
   * INTERNAL VARIABLES: Airflow, Heat & Moisture Removal
   ****************************************************************************/
  Modelica.Units.SI.VolumeFlowRate Q_wind "Wind-driven ventilation flow rate (m3/s)";
  Modelica.Units.SI.VolumeFlowRate Q_stack "Thermal buoyancy stack flow rate (m3/s)";
  Modelica.Units.SI.VolumeFlowRate Q_vent_total "Total ventilation volumetric rate (m3/s)";
  Modelica.Units.SI.MassFlowRate Mdot_vent "Total air mass exchange rate (kg/s)";
  Modelica.Units.SI.HeatFlowRate Q_vent_heat "Heat removal rate by natural ventilation (W)";
  Modelica.Units.SI.Pressure VP_amb_sat "Outdoor ambient saturation vapor pressure (Pa)";
  Modelica.Units.SI.Pressure VP_amb_out "Outdoor ambient vapor pressure (Pa)";
  Modelica.Units.SI.MassFlowRate Mdot_v_vent "Moisture removal rate by natural ventilation (kg/s)";

  parameter Modelica.Units.SI.Density rho_air = 1.18 "Air density (kg/m3)";
  parameter Modelica.Units.SI.SpecificHeatCapacity cp_air = 1006 "Air specific heat (J/(kg.K))";
  parameter Real R_gas = 8314.0 "Universal gas constant (J/(kmol.K))";
  parameter Real M_H2O = 18.015 "Molar mass of water vapor (kg/kmol)";

equation
  /****************************************************************************
   * GOVERNING VENTILATION EQUATIONS (Equations 2.2, 2.4, 2.5, 2.6 in Thesis)
   ****************************************************************************/
  Q_wind = Cd_mesh * A_vent_side * max(0.1, wind_speed) * sqrt(delta_Cp);
  Q_stack = Cd_mesh * A_vent_roof * sqrt(2 * 9.81 * dh_stack * max(0.0, T_air_in - T_amb_out) / max(273.15, T_amb_out));
  Q_vent_total = sqrt(Q_wind^2 + Q_stack^2);
  Mdot_vent = rho_air * Q_vent_total;
  Q_vent_heat = Mdot_vent * cp_air * (T_air_in - T_amb_out);

  // Apply sensible heat removal directly to thermal network (positive leaving port)
  heatPort.Q_flow = Q_vent_heat;

  // Outdoor ambient vapor pressure from Tetens formulation
  VP_amb_sat = 610.78 * exp(17.27 * (T_amb_out - 273.15) / max(1.0, (T_amb_out - 273.15 + 237.3)));
  VP_amb_out = max(0.0, min(VP_amb_sat, RH_amb_out * VP_amb_sat));

  // Natural ventilation moisture exchange rate (kg/s)
  // Positive value denotes moisture mass flow escaping from greenhouse interior to outdoor ambient
  Mdot_v_vent = Q_vent_total * (M_H2O / R_gas) * (massPort.VP / max(273.15, T_air_in) - VP_amb_out / max(273.15, T_amb_out));

  // Apply moisture removal to water mass port (positive entering component = leaving greenhouse air)
  massPort.MV_flow = Mdot_v_vent;

  // Telemetry outputs
  Q_vent = Q_vent_heat;
  MV_vent = Mdot_v_vent;
  ACH = (3600 * Q_vent_total) / V_gh;

  annotation (
    Icon(coordinateSystem(preserveAspectRatio=false, extent={{-100,-100},{100,100}}),
         graphics={
           Rectangle(extent={{-90,90},{90,-90}}, lineColor={0,128,128}, lineThickness=1.5,
                     fillColor={230,248,248}, fillPattern=FillPattern.Solid),
           // 16-Mesh Grid Lines (representing wire mesh screen)
           Line(points={{-80,60},{80,60}}, color={0,128,128}, pattern=LinePattern.Dot),
           Line(points={{-80,30},{80,30}}, color={0,128,128}, pattern=LinePattern.Dot),
           Line(points={{-80,0},{80,0}}, color={0,128,128}, pattern=LinePattern.Dot),
           Line(points={{-80,-30},{80,-30}}, color={0,128,128}, pattern=LinePattern.Dot),
           Line(points={{-80,-60},{80,-60}}, color={0,128,128}, pattern=LinePattern.Dot),
           Line(points={{-60,80},{-60,-80}}, color={0,128,128}, pattern=LinePattern.Dot),
           Line(points={{-30,80},{-30,-80}}, color={0,128,128}, pattern=LinePattern.Dot),
           Line(points={{0,80},{0,-80}}, color={0,128,128}, pattern=LinePattern.Dot),

08. ขั้นตอนที่ 7: การติดตั้งและโมเดลเซนเซอร์ 15 จุด 3 มิติ (Spatial Sensor Telemetry)

ขั้นตอนที่ 7.1

การจำลองการกระจายตัวของอุณหภูมิและความชื้น (Microclimate Stratification)

โรงเรือนอู่ทองติดตั้งเซนเซอร์วัดอุณหภูมิและความชื้นจริง 15 จุด (5 เสา $ imes$ 3 ระดับความสูง) แบบจำลองดิจิทัลทวินได้บรรจุฟิสิกส์ 2 มิติที่สมจริง:
• Longitudinal Gradient: อากาศจากลมประจำถิ่น WSW พัดผ่านมุ้งฝั่งเสา C (ต้นลม - อุณหภูมิต่ำสุด) รับความร้อนสะสมไปเรื่อยๆ จนถึงเสา B (ท้ายลม - อุณหภูมิสูงสุด)
• Vertical Gradient: ปรากฏการณ์แรงลอยตัวอุณหภูมิ (Thermal Buoyancy Plume) ทำให้ความร้อนลอยตัวสะสมใต้แนวสันหลังคาโค้ง (ระดับ Top สูงกว่าระดับ Canopy และ Bottom)

ตำแหน่งเสา ทิศทางทางภูมิศาสตร์ สภาวะการรับลม (ERA5 WSW) ระดับ Top (z=2.5m) ระดับ Mid (z=2.0m) ระดับ Bot (z=1.2m)
Pole C ตะวันตกเฉียงใต้ (SW) ต้นลม (Windward) ปะทะลมตรง T_sensor_C_Top T_sensor_C_Mid T_sensor_C_Bot
Pole B ตะวันออกเฉียงเหนือ (NE) ท้ายลม (Leeward) อากาศสะสมความร้อน T_sensor_B_Top T_sensor_B_Mid T_sensor_B_Bot
Pole E กึ่งกลางโรงเรือน (Center) แกนกลางอ้างอิง T_sensor_E_Top T_sensor_E_Mid T_sensor_E_Bot
Pole A & D ตะวันตกเฉียงเหนือ (NW) & ออกเฉียงใต้ (SE) ด้านข้างขนานแนวลม T_sensor_A/D_Top T_sensor_A/D_Mid T_sensor_A/D_Bot
สมการคำนวณการไล่ระดับอุณหภูมิ 15 จุดใน Suphanburi_Greenhouse.mo 
  // Gradient แนวนอนตามทิศทางลม WSW (WSW พัดจากเสา C ไปยังเสา B)
  dT_spatial_longitudinal = (T_air_degC - (T_amb_actual - 273.15)) * (0.045 / max(0.4, u_wind_actual));
  
  // Plume แนวดิ่งใต้หลังคาโค้ง (Stack effect)
  dT_thermal_buoyancy = max(0.0, (T_air_degC - (T_amb_actual - 273.15))) * 0.12;

  // เสา C (ต้นลม - เย็นที่สุด):
  T_sensor_C_Top = T_top_base - 0.7 * dT_spatial_longitudinal;
  T_sensor_C_Mid = T_mid_base - 0.8 * dT_spatial_longitudinal;
  T_sensor_C_Bot = T_bot_base - 0.9 * dT_spatial_longitudinal;

  // เสา B (ท้ายลม - ร้อนที่สุด):
  T_sensor_B_Top = T_top_base + 0.8 * dT_spatial_longitudinal;
  T_sensor_B_Mid = T_mid_base + 0.9 * dT_spatial_longitudinal;
  T_sensor_B_Bot = T_bot_base + 1.0 * dT_spatial_longitudinal;
